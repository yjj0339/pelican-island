# 鹈鹕单车

一只戴头盔的鹈鹕骑着复古单车环岛：实时骨骼蹬踏、压弯、跳台滑翔、用喉囊接鱼，有昼夜变化和合成音乐。

**在线游玩：** https://yjj0339.github.io/pelican-island/

单个 `index.html`，Three.js r128（cdnjs）渲染，音效全部用 Web Audio 实时合成。

## 操作

| 键盘 | 触屏 | 作用 |
|---|---|---|
| W / ↑ | 蹬 | 蹬踏（Shift 站起冲刺） |
| S / ↓ | 刹 | 刹车 |
| A D / ← → | 左 / 右 | 转向 |
| 空格 | 跳 | 起跳，空中按住扑翼滑翔 |
| Q / E | — | 换档 |
| B | 铃 | 按铃 |
| C / T / M / N | 顶部按钮 | 视角 / 昼夜 / 声音 / 音乐 |

手机竖着拿时，右上角「横屏」按钮可以把整个画面转成横屏。iPhone 用 Safari「添加到主屏幕」后打开就是全屏。
